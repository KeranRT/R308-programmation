# R308 - Programmation Python

TP de BUT2 Réseaux et Télécommunications. Python 3.10 minimum, sans bibliothèque externe.

Depuis la racine du dépôt :

```text
python TP1/partie_a.py
python TP1/partie_b.py
python TP1/partie_c.py
python TP1/partie_d.py
python TP2/main.py
python TP3/main.py
```

TP1 : dictionnaire de notes, devinette, mots et pendu (7 erreurs).
TP2 : morpion contre une IA aléatoire. Les lignes et colonnes vont de 0 à 2.
TP3 : bibliothèque avec menu et sauvegarde dans `TP3/livres.csv`.
Le chargement du CSV reconstruit les utilisateurs qui ont un emprunt en cours.
Les utilisateurs sans emprunt ne sont pas enregistrés dans ce format.

Les parties obligatoires sont réalisées ; les extensions et bonus ne sont pas inclus.
